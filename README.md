# 拉麺帖（ラーメン記録）

行ったラーメン屋を、店名ですぐ引けるスマホ用アプリ（PWA）。

- 近くの店：位置情報で近い順に5軒出し、「行った」を1タップで記録。地図にない店は店名を手で足すと、その場所を覚えて次から候補に出る。Googleの店検索のキーが入っていれば、Google（Nearby Search、種類「ラーメン屋」、半径2km）にも同時に聞いて合わせる。地図の店と同じ店（すぐそばで名前が重なる）は足さない。同じあたり（約1km四方）は1週間覚えて聞き直さない（`ramenlog.nearGoogle`）。
- 札幌市内の店は `data/sapporo-ramen.json` に入れてある（OpenStreetMap から取得）。札幌の外では OpenStreetMap の検索サーバー（Overpass）に聞く。
- 「行った」の直後に、頼んだもの・★（タップ）・写真（スマホの写真から選ぶ。アプリには長い辺1280pxに縮めた控えを IndexedDB に保存）・メモを入れる画面が出る。「あとで」で閉じて、店の詳細からあとで入れてもいい。
- 行った店の一覧：ふだんは10軒まで（「もっと見る」で全部）。並べ方は回数順・最近行った順・★の高い順を切りかえられる。地図は一覧の上（店名で探している間は一覧の下）。
- 地図で見る：行った店にピン（数字は回数、3回以上は赤）。ピンをタップすると店の記録へ。検索すると地図も絞られる。地図の絵は OpenStreetMap のタイル、地図の部品は Leaflet 1.9.4（`vendor/leaflet/`）。
- おすすめ：★4以上なのに30日以上行ってない店を「また行こう」、★と頼んだもの・店名の言葉（味噌・塩・つけ麺など）から好みを推し量り、行ったことのない店を3軒まで「未訪問」として出す（今いる場所か最後に行った店から10km以内）。未訪問の店をタップすると地図に☆で出る。Googleの店検索のキーが入っていれば、いちばん好きな味（例：味噌ラーメン）で近くの店を Google にも1回聞いて候補に足す。同じ味・同じあたり（約2km四方）は1週間覚えて聞き直さないので、検索するのは知らない場所に行ったときだけ（`ramenlog.recGoogle`）。
- Googleの店検索（Places API (New) の Text Search）：キーを画面の「Googleの店検索」に入れると、検索窓の「Googleで探す」で Google にある店を最大5件出して「行った」を押せる。Googleマップからの共有も、店名で Google に場所を聞いて OK だけで足せる。キーはファイルに書かず、そのスマホの localStorage にだけ置く（キーは Google Cloud で harden22n.github.io からだけ・Places API (New) だけに制限し、1日の回数の上限をつける）。
- 店名で検索（全角半角・カタカナひらがなの違いは気にしなくていい）。行った店に加えて、行ってない店も札幌の店リスト（ラーメン店＋それ以外の飲食店 `data/sapporo-food.json`）・前に調べた場所・手で足した店から20件まで出し、「地図」「行った」を押せる。見つからない店は「Googleマップで探す」で確かめて、「地図で場所を選んで店を足す」で地図をタップして足せる。
- Googleマップから足す：Android は Googleマップの「共有」→「拉麺帖」（manifest の share_target）。共有のテキストを検索窓に貼っても足せる（iPhone 用）。リンクに座標があればそれを使い、なければ住所を国土地理院の住所検索（msearch.gsi.go.jp）で場所にする。Googleマップの短いリンク（maps.app.goo.gl）はブラウザから中身を読めない（座標も入っていない）ので、リンクだけのときは店名を聞いてから、Googleマップでコピーした住所を検索窓に貼るか、地図をタップして場所を決める。
- バックアップ：「Obsidianに保存」で保管庫の `プロジェクト/ラーメン記録/拉麺帖バックアップ.md` に上書き保存（obsidian:// のリンクを使う）。JSON ファイルへの書き出しもできる。読み込みは .json と .md のどちらでもよく、今の記録に足すだけで消さない。
- 記録はスマホのブラウザの中（localStorage）に保存する。
- みんなで共有（`sync.js`）：Google でログインし、合言葉のグループに入ると、店・行った日・頼んだもの・★・メモ・記録した人の名前を Firebase（Firestore）でそろえる。写真は共有しない（各自のスマホの中だけ）。直せるのは自分の記録だけ。「みんなの記録／自分の記録」で数え方を切りかえられる。おすすめは自分の記録だけから選ぶ。
  - 設定は `firebase-config.js`（null のあいだは共有の欄が出ない）。守りのルールは `firestore.rules` を Firebase コンソールに貼る。

## ファイル
- `index.html` `style.css` `app.js` … 画面と動き
- `sw.js` `manifest.webmanifest` `icons/` … ホーム画面に置くための設定（ファイルを直したら `sw.js` の `CACHE` の番号を上げる）
- `data/sapporo-ramen.json` … 札幌のラーメン店リスト（`data/sapporo-food.json` はそれ以外の飲食店、検索用）。取り直すときは `node tools/update-sapporo.mjs`
- `sync.js` `firebase-config.js` `firestore.rules` … みんなで共有
- `vendor/markercluster/` … 地図の近くのピンをまとめる部品 Leaflet.markercluster 1.5.3（MIT）
- `vendor/leaflet/` … 地図を出す部品 Leaflet 1.9.4（BSD-2-Clause）
- `design/` … デザインの見本（決定.html が採用案）

店と地図のデータ © OpenStreetMap contributors（ODbL）
